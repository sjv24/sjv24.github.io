Case Study

Internly – Internship Management Platform

Internly connects students with companies offering internships. It streamlines the process of posting, applying, and managing internships, making life easier for both students and employers. I first built it as a university team project, and then rebuilt it on my own as Internly v2.

Node.js PostgreSQL JavaScript Full-Stack

Internly v2: A Solo Rebuild

After building the original Internly with my team, I rebuilt it on my own. I kept the plain HTML, CSS, and JavaScript front end, but rebuilt the backend properly with Node.js, Express, and PostgreSQL: a structured codebase instead of one large file, real per-user login sessions, and automated tests.

Current Features

  • Search internships by keyword, location, and type, with pagination. The filtering runs in the database and updates as you type.
  • Student and company accounts with secure sign up and login (hashed passwords, per-user sessions in httpOnly cookies).
  • Students apply with a PDF resume and a cover note, track every application, and withdraw pending ones.
  • Companies post, edit, and delete their own listings, review applicants, open resumes, and accept or reject.
  • AI CV match: paste a CV and get the best-matching internships, each with a score, the skills that matched or are missing, and an explanation that streams in live.
  • Security basics: role and ownership checks, input validation, parameterised SQL, XSS and CSRF protection, rate limiting, and private resume storage.
  • 49 automated tests, including security checks.

Why This Project?

My friends and I noticed that many students struggled to find internships, and companies often had a hard time managing applications efficiently. So we wanted to build a solution that simplifies this process, making it transparent, organized, and user-friendly. Internly is designed to solve real-world problems while showcasing my skills in full-stack web development.

How It Works?

Internly v2 uses HTML, CSS, and JavaScript for the front end, with Node.js and Express handling the backend and PostgreSQL as the database (the original version used MySQL). Students can create accounts, browse internship listings, and apply directly through the platform. Companies can post internships, track applications, and manage their profiles. Everything is stored in the database and updates dynamically based on user actions.

Takeaways

Building Internly taught me a lot about full-stack development and database management. I gained hands-on experience with Node.js, SQL, and frontend-backend integration. This project also helped me understand how to design user-friendly interfaces, validate forms, and handle dynamic data efficiently.

Rebuilding it on my own taught me what the first version skipped: how login sessions and cookies really work, the difference between authentication and authorisation, how database constraints and indexes help, how to defend against common attacks like XSS, CSRF, and SQL injection, and how to write automated tests.
