Case Study

Internly

Internly is an internship portal where students find and apply for internships, and companies post listings and manage the people who apply.

React TypeScript Node.js Express PostgreSQL

The Journey

  1. July 2025

    It started as a university project

    My friends and I kept seeing the same problem from both sides: students struggled to find internships, and companies had a hard time keeping track of who applied. So we built Internly as a university project, one place where companies post internships and students search, apply, and follow up.

  2. October 2026

    Rebuilding it on my own

    The first version worked, but the whole backend was one 800-line file, every visitor shared a single login session, and there were no tests. So I rebuilt it solo with a structured Express backend, PostgreSQL in place of MySQL, real per-user logins, and protection against attacks like XSS, CSRF, and SQL injection. I kept the front end in plain HTML, CSS, and JavaScript so I could focus on getting the backend right.

  3. November 2026 · Now

    A React and TypeScript version

    Next I moved the whole app to React 19 and TypeScript, with the web app, the API, and a shared set of types living in one repository so both sides always agree on the data. Students search as they type, apply with a resume, and track every application; companies post listings and review applicants; and an AI CV match ranks the best-fitting internships and explains why.
