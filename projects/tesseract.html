Case Study

Tesseract

Tesseract is a chatbot that answers anything about the movie Interstellar, whether it's the plot, the physics, or what fans think, by sending each question to the source that actually has the answer.

Python LangGraph RAG FastAPI React Weaviate

The Journey

  1. May 2026

    It started as a class project

    Tesseract began as our final project for CSCI 370. We picked Interstellar because the questions people ask about it fall into very different buckets: the plot, the real physics behind it, and endless debates about the ending. No single source covers all of that, so we set out to build one chatbot that knows where to look: the screenplay, Kip Thorne's The Science of Interstellar, or over 41,000 YouTube comments.

  2. October 2026

    Rebuilding it from scratch

    The first version worked, but it was notebooks stitched into a Streamlit app, and nobody had ever measured how good its answers really were. So I rebuilt it on my own as a proper full-stack app, with a React and TypeScript front end, a FastAPI backend, and a LangGraph agent, and wrote a set of test questions first so that every change could be measured.

  3. November 2026 · Now

    Where it is today

    Tesseract v2 answers with page-numbered citations, counts comments with code instead of letting a model guess, and every change is logged against a 106-question golden set.

    83%right passage in the top 5, up from 57%
    92%questions sent to the right source, up from 87%
    100%answers faithful to their sources, up from 95%
